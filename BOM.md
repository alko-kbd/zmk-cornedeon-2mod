# BOM - handwired ZMK Cornedeon 2MOD

| Component | Specification / Description | Qty | Notes |
| :--- | :--- | :--- | :--- |
| **MCU** | Nice!Nano (nRF52840) | 2 pc | v1 or v2, I use a clone from Aliexpress. |
| **Switches** | Any low profile (Cherry, Gateron, Kailh) | 48 pcs | Chosen by preference (linear, tactile, clicky). |
| **Sockets** | A connector for your switch type, the body is printed on a 3D printer. | 48 pcs | The socket housing differs for different types of switches. Here are my sockets for Gateron LP. |
| **Diodes** | 1N4148 (through-hole, DO-35 package) | 48 pcs | One diode per switch to prevent ghosting. |
| **Battery** | Li-Po 602530, 400 mAh | 2 pc | Turn on Nice!Nano charge boost for battery more 500 mAh. |
| **Joystick** | Joystick with Hall Effect | 1 pc | For Nintendo Switch. |
| **Trackpad** | TPS43 trackpad | 1 pc | I2C interface. |
| **Power Switch** | Slide switch 20x6 mm | 2 pc | [Ali](https://aliexpress.ru/item/4000699324084.html) |
| **Reset Button** | Tacktile micro button 4x4 mm | 2 pc | [Ali](https://aliexpress.ru/item/1005005633442363.html) |
| **Keycaps** | Low profile keycap set for your switches (mx, choc) | 1 set | On photo - my 3D printed keycaps. |
| **Wires** | 1-core copper wire PTFE 28 AWG | 3 meters | [Ali](https://aliexpress.ru/item/1005007700772616.html) |
| **Case** | 3D-printed | 1 set | STL files on "case" directory. |
| **Feet** | Silicone self-adhesive bumpons | 8 pcs | Prevents the keyboard from sliding on the desk. |
